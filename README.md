## 👋 About me

I build **agentic AI for autonomous unmanned aerial vehicles** in the [ASQI Lab](https://ma-hossain.github.io/) at [Middle Tennessee State University](https://www.mtsu.edu/). Drones that plan, adapt, and navigate on their own rather than following a fixed script.

Before the Ph.D. I spent **three years in security operations and threat intelligence**. Both halves ask the same question: *how much can you let a system decide for itself?*

An autonomous agent reads untrusted input from the world and then acts on it, which is also a fair description of an attack surface. My research is about making agents **capable enough to be useful and verifiable enough to deploy**.

## 🔬 Research

Four questions I'm working on. Autonomous flight on one side, security on the other.

| # | Thread | The question | Keywords |
|:-:|--------|--------------|----------|
| 01 | **Agentic AI for Autonomous UAVs** <br/>`PRIMARY FOCUS` | Can a drone plan its own mission, revise the plan when the world disagrees, and still stay within safe bounds? | Self-evolving agents · Autonomous navigation · ROS · Sensor fusion |
| 02 | **Security of Agentic Systems** <br/>`ACTIVE` | An agent that reads the world and acts on it is also an attack surface. What breaks it? | Prompt injection · Tool misuse · Adversarial robustness · Threat modeling |
| 03 | **Knowledge Graphs for Threat Intelligence** <br/>`ONGOING` | Can synthetic intelligence be realistic enough to train on and traceable enough to trust? | STIX 2.1 · Link prediction · Graph neural networks · Synthetic data |
| 04 | **Evaluation & Assurance** <br/>`ONGOING` | How do we make claims about autonomous systems that hold up to scrutiny? | Benchmarks · Reproducibility · Simulation · Red teaming |

**Areas of interest:** Agentic AI · Autonomous Systems & UAVs · Knowledge Graphs · Cyber Threat Intelligence · Machine Learning Security · Computer Vision & Perception
